# Unterrichtscockpit

Local-first Progressive Web App für die persönliche Unterrichtsplanung und -durchführung auf dem iPad.

## Entwicklungsstatus

Entwicklungsstufe 1: Initialisierung. Noch nicht produktiv freigegeben. Keine realen Unterrichtsdaten verwenden, bis Datensicherung und Wiederherstellung implementiert und getestet sind.
